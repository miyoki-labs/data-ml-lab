# Git 実戦教材

読みながら手を動かして、「荒れたリポジトリを片付ける」力をつける教材です。
`notes/git.md`（用語と出力の読み方）の実践編にあたります。

## 進め方（1 章 15〜20 分の目安・未測定）

1. 練習場を作る（1 回だけ。作り直すときは `-Force`）

   ```powershell
   pwsh -File scripts/git-practice-setup.ps1
   ```

   `C:/GitPractice/` の下に、荒れたリポジトリ（`work`）と、その保管先（`origin.git`）ができます。
   本物のリポジトリには触りません。練習場の中だけで壊してかまいません。
2. 章を開き、**「予想」を先に書く**（コマンドを打つ前に）
3. 「見本」を読み、「穴あき」を埋めて実行し、予想と見比べる
4. 最後に「自分の 1 行」を自分の言葉で書く

## ルール

- 本物のリポジトリでは **読み取りのコマンドだけ**使う（`status`・`log`・`branch`・`worktree list`・`cherry`・`range-diff`）。
  書き換える練習（`rebase`・`reset`・`worktree remove`）は練習場だけ。
- 章の「実行ログ」は [run-log.md](run-log.md)。**予想を書いたあとで**開く（先に見ると予想の練習にならない）。
- 手順を直すときは、練習場で最初から通して確かめてから書く。
- この教材は公開リポジトリに置く前提＝技術の話だけを書く。自分や他人の案件の固有名は入れない。
